# Pillars_of_Sustainability

Sustainability and sustainable behaviour were important in many different cultures 
before this term gained popularity in the modern environmental movement. 
Although the most common association with sustainability is environment, 
it is only one part of sustainability. Actually sustainability is based on three pillars. 
Environmental, economic and social sustainability (Purvis, et al. 2017). 
Using Natural Language Processing (NLP) and Large Language Models (LLMs) 
we will research each of the three pillars of sustainability and what influences them. 
So far, the planning phase of this project is finished.
